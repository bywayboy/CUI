# CUI UI 设计器设计方案

> 状态：M0–M4 已落地（2026-11-20）。设计工程 `.cui`、布局运行时、设计器壳、
> 分组代码生成与 headless 测试均已接入。

## 1. 文件模型

- `.cui` 是唯一设计工程文件（UTF-8 JSON，`format: "cui-design"`, `version: 1`）。
- 打开/另存只过滤 `*.cui`；生成出来的 `.ui.c/.ui.h` 不是设计文件。
- 一个 `.cui` 可包含多个窗口和虚拟 Dialog。
- **生成组**是代码生成单元：
  - 单成员组 = 单独输出；
  - 多成员组 = 多个窗口/Dialog 输出到同一对 `.ui.c/.ui.h`；
  - 一个窗口/Dialog 只属于一个组。

顶层结构：

```json
{
  "format": "cui-design",
  "version": 1,
  "name": "project",
  "groups": [
    { "id": "main", "name": "主分组",
      "outputC": "main.ui.c", "outputH": "main.ui.h",
      "symbolPrefix": "Main" }
  ],
  "windows": [
    { "id": "main", "kind": 0, "group": "main", "root": { } }
  ]
}
```

`kind`: `0 = Native Window`，`1 = Virtual Dialog`。

## 2. 布局

支持混合布局：

- `Absolute`：x/y/w/h + 四边锚点/margin；
- `Column` / `Row`：主轴 fixed/auto/fill/grow，gap、padding、交叉轴 align；
- `Grid`：Grid Cols、Grid Rows（0 = 自动按子节点增长）、行/列间距、
  子项跨行/跨列；子项默认铺满单元格；
- `Panel`：视觉容器；
- 所有节点可嵌套。

属性页可编辑：

- 宽高模式、宽高、min/max、Grow、Align；
- Padding L/T/R/B、Gap；
- X/Y；
- Grid 容器：Grid Cols、Grid Rows (0=自动)、Row Gap、Col Gap；
- Grid 子项：Grid Row、Grid Col、Row Span、Col Span（-1 = 自动排布）。

设计画布：

- 选中、拖拽（Absolute 父级内）、八向缩放（按手柄方向只改对应边）、
  对齐辅助线/4px 吸附；
- 组件树支持拖动改父级/排序，`Ctrl` 多选、空白拖动框选；
- 设计态渲染静态预览，预览态使用真实控件运行时。

## 3. 运行时

新增 `src/ui/ui_design.h/.c`：

- 模型增删/查找/复制/移动；
- JSON 读写；
- 布局计算；
- 组件运行时；
- 分组代码生成。

运行时实例：

```c
UiDesignInstance inst;
UiDesignInstance_Init(&inst, doc, windowIndex, ui, pm, ime);
UiDesign_Draw(&inst, rc);
UiDesign_DrawOverlay(&inst);
```

支持的控件：`Panel / Absolute / Column / Row / Grid / Label / Button /
Input / Checkbox / Switch / Slider / Progress / Select / Image / Separator`。
复杂组件后续按同一注册表扩展。

## 4. 生成代码

每个生成组输出一对 C/H：

```c
UiDesignDoc *Main_Doc(void);

#define Main_WIN_MAIN 0

void Main_main_Init(UiDesignInstance *inst, UiContext *ui,
    UiPopupManager *pm, UiIme *ime);
void Main_main_Draw(UiDesignInstance *inst, UiRect rc);
```

虚拟 Dialog：

```c
int  Main_dialog1_DialogOpen(UiDesignInstance *inst, UiId owner);
void Main_dialog1_DialogDraw(UiDesignInstance *inst);
```

- 不生成 WinMain/消息循环/窗口创建；窗口生命周期由应用框架调用。
- Dialog 是宿主内的 `UiDialog` 覆盖层，不创建独立 HWND。
- 生成文件带 `Generated by CUI Designer` 标记，设计器不把它们当 `.cui` 打开。
- 生成是确定性的；输出路径相对 `.cui` 所在目录，绝对路径也可用。
- 生成前先弹预览：逐文件标注 `新增 / 更新 / 未变` 与行数变化，
  确认后才写入；校验（重复 ID、输出冲突、窗口无根节点）不过则直接阻止。

宿主集成示例（生成代码由应用框架调用）：

```c
#include "main.ui.h"

static UiDesignInstance gInst;

/* 窗口创建后 */
Main_main_Init(&gInst, &app->ui, &app->pm, &app->ime);

/* 每帧绘制 */
Main_main_Draw(&gInst, contentRc);

/* Dialog 窗口 */
if (Main_dialog1_DialogOpen(&gInst, ownerId))
    Main_dialog1_DialogDraw(&gInst);
```

## 5. 设计器

`bin\cui_designer.exe`：

- 顶部：`UiNavBar` 菜单栏（文件 / 编辑 / 工程 / 视图），不直接堆按钮；
- 第二行：
  - 布局 `UiButtonGroup`：选择、自由、列、行、Grid、面板；
  - 组件 `UiButtonGroup`：标签、按钮、输入、复选、开关、滑块、进度、下拉、图片、分隔；
  - 右侧图标按钮：删除/复制/上移/下移/预览；
- 插入流程：选布局或组件工具 → 在设计画布点击目标容器 → 插入；
  `Esc` 或“选择”工具退出插入模式；
- 左侧：窗口/生成分组 + 当前窗口组件树；
  - 组件树支持拖动重排/改父级；`Ctrl` 点选多选，空白拖动框选；
- 中间：窗口标签 + 设计画布（静态预览/运行时预览）；
  - 选中容器显示 padding 内框、gap 带、Grid 轨道和容器方向；
  - 拖动吸附父/兄弟边缘与中心并显示参考线；
  - `Ctrl+滚轮` 缩放，`Space+拖动` 平移；
- 右侧：属性页与组件表；
  - 属性分节可折叠：基本 / 布局 / 尺寸与位置 / 内容 / 事件 / 输出，
    内容超出可滚动；`Shift+拖动` 数值属性快速调整；
  - 属性页顶部是布局约束组：宽/高模式（固定/自动/填充/伸展）、
    对齐（起点/居中/末端）、容器方向（列/行/Grid/自由）；
  - 组件表只列当前窗口可达节点，删除后的节点不再出现。

快捷键：

- `Ctrl+N/O/S` 新建/打开/保存；
- `Ctrl+Z/Y` 撤销/重做；
- `Ctrl+D` 复制组件；
- `Ctrl+G` 生成预览；
- `Delete` 删除组件；
- 方向键微调 Absolute 子节点，Shift 步长 8；
- `Esc` 结束属性编辑/退出预览。
