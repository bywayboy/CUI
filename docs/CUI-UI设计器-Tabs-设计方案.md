# CUI UI 设计器 Tabs 设计方案

> 状态：已实施（M1–M4，2026-11-24）。
> 构建与 headless 回归通过；本文保留设计推演过程，实际落地与差异见 §13。
> 现有运行时能力见 [CUI-Tab-设计方案.md](CUI-Tab-设计方案.md)。

## 1. 结论先行

设计器里的 Tabs 目前不是“从零缺失”，而是**原型级支持**：

- 能从组件面板插入；
- 能绘制 Line / Pill / Card 页签；
- 能点击页签切换；
- 能布局、预览、写 JSON、生成代码；
- 但页面没有一等管理能力，`selected` 在增删/移动页面后可能失效，
  Card 样式在运行时也没有真正闭环。

本轮建议把它升级成**设计器一等容器**。优先级不是继续加图标、关闭按钮、
Badge 等视觉能力，而是先解决：

1. 页面身份与 `selected` 的强一致；
2. 页面新增/复制/删除/重排的设计器闭环；
3. 树、画布、属性页、预览对“当前页”的统一语义；
4. 静态画布、运行时、生成代码三者的一致性；
5. Card 样式与空页状态；
6. 回归测试。

## 2. 现状审计

### 2.1 已有能力

| 层 | 现状 |
|---|---|
| 模型 | `UI_DN_TABS` 是容器；直接子节点即页面；页面文字取子节点 `name`；`selected` 是当前页索引；`variant` 为 Line/Pill/Card |
| 布局 | `dn_layout_node` 先按 variant 让出 header 高度，所有页面重叠在同一页区，并逐页递归布局 |
| 命中 | `dn_hit_node` 只命中当前 `selected` 页 |
| 运行时 | `dn_draw_node` 调 `UiTabBar_Draw`，页签文字来自全部直接子节点；点击后更新 `n->selected` 并发 change 事件；只绘制当前页 |
| 设计器 | 调色板可插入 Tabs；`d_tabs_add_pages` 默认创建 2 个 Column 页；静态画布自行绘制 header；点击页签切换；属性页可改当前页索引和样式 |
| 树 | 页面与内容都在树中可见；选中非活动页内的节点时，`d_tabs_reveal` 会自动切换活动页 |
| 代码生成 | `cg_node` 已输出 `selected` / `variant`；Tabs 页面不输出宽高和 x/y，因为尺寸由页区覆盖 |
| 测试 | 仅覆盖类型解析、两页共享页区布局、`selected` JSON 往返、`"type":"tabs"` |

### 2.2 关键缺口

1. **没有页面 CRUD 闭环**
   - 插入 Tabs 时自动生成两页；
   - 想再加一页，只能借助通用节点的技巧，页面语义不明确；
   - 没有“在当前页之后新增页”“复制页”“删除页”“页面上移/下移”的一等入口。

2. **`selected` 没有强一致**
   - 通用 `UiDesign_NodeRemove` 删除页面后不修正父 Tabs 的 `selected`；
   - `UiDesign_NodeMoveUp/Down` 重排页面后不跟随原选中页；
   - 拖拽重排、跨父级移动也会留下错误索引；
   - 可能越界、指错页，或者页面删空后仍保留旧索引。

3. **页面结构约束缺失**
   - Tabs 的直接子节点就是页面，但任意类型都能成为页面；
   - 页面可以被拖出 Tabs，普通节点也可以被拖进 Tabs 后“意外变成页面”；
   - 新页面固定是 Column，但旧工程的叶子页、跨父级拖拽都没有规则。

4. **“选中节点”和“活动页”耦合且不完整**
   - 点击页签会切换 `selected` 并选中页面节点；
   - 树中选中非活动页后代时，`d_tabs_reveal` 会顺带改 `selected`，但没有统一走编辑/脏标记/撤销路径；
   - 用户编辑非活动页时，页面切换发生得隐式，状态提示不足。

5. **静态画布与运行时绘制重复**
   - `d_tabs_item_at` / `d_tabs_draw_header` 自己重新计算宽度、间距、颜色；
   - 运行时由 `UiTabBar_Draw` 计算；
   - 两套逻辑容易在 padding、指标宽度、Pill 背景、Card 结构上漂移。

6. **Card 样式未闭环**
   - `UiTabBar_Draw` 在 Card 下**延迟**绘制活动页签；
   - 需要调用 `UiTabBar_DrawActive` 才能画活动页签底色、文字和边框；
   - 设计器运行时 `dn_draw_node` 没有调用它，所以 Card 的活动页签实际是空白/不完整；
   - 静态画布也没有内容面板底色和正确的两阶段顺序。

7. **溢出与上限没有策略**
   - `UiTabBar_DrawEx` 在页签超宽时直接停止绘制后面的项，没有滚动、省略菜单；
   - 运行时 `labels[32]` 和 32 位 `disabledMask` 决定了当前上限是 32 页；
   - 设计器可以创建更多页，但没有校验和提示。

8. **预览会写回模型状态**
   - 预览复用 `g_d.doc`；
   - 运行时点击页签会把 `UiDesignNode.selected` 写回设计文档；
   - 当前没有明确的“预览状态是否持久化”规则，可能在退出预览后改变设计页签。

9. **测试覆盖不足**
   - 页面增删、重排、`selected` 修正、结构约束、Card 顺序、空页、生成代码上限都没有回归覆盖。

## 3. 目标与非目标

### 3.1 本轮目标

- Tabs 成为设计器一等容器：页面可新增、复制、删除、重命名、重排、切换。
- 页面身份使用稳定节点身份；`selected` 在所有结构变更后始终有效。
- 统一“活动页 = 页面区显示页 = 属性页当前页 = 树中自动揭示页”。
- 设计器画布、运行时预览、生成代码行为一致。
- Line / Pill / Card 三种样式在静态画布和运行时都完整可见。
- 明确 32 页上限与溢出提示。
- 建立模型层、生成代码层和设计器交互层的回归测试。

### 3.2 本轮非目标

- 页签图标、Badge、可关闭页签、tooltip；
- 单独禁用某个页签（区别于禁用页面内容）；
- 页签横向滚动、溢出下拉菜单；
- 垂直页签；
- `UiTabPager` 转场动画接入设计器/生成代码；
- 页面路由、懒加载、URL 绑定；
- 页签文字与页面节点名称彻底解耦（独立 `tabLabel` 字段）。

这些能力可以后续扩展，但不应该阻塞本轮页面管理闭环。

## 4. 页面模型选型

### 4.1 候选方案

| 方案 | 做法 | 优点 | 代价 |
|---|---|---|---|
| A. 直接子节点即页面 + 页面约束 | 保持现有结构，在节点 ID/名称上补元数据和管理 API | 兼容旧 `.cui`；布局/代码生成改动小；运行时无需新类型 | 页面语义靠约束保证；通用节点 API 要补 Tabs 特判 |
| B. 新增 `UI_DN_TABPAGE` 包装节点 | Tabs 下只允许 TabPage，页面内容放在其下 | 语义最清晰；CRUD 和后续元数据最自然 | 旧文档迁移；多一层节点；布局、命中、代码生成、树都要改 |
| C. Tabs 节点持并行页面元数据数组 | 页面内容仍是子节点，标签/状态另存数组 | 模型字段看似集中 | 数组与子节点索引强耦合；重排/删除极易失配，不推荐 |

### 4.2 推荐：方案 A

理由：

- 现有 `.cui`、布局、命中、生成代码都按“直接子节点 = 页面”工作；
- 页面数量通常不大，真正缺的是管理 API 和不变量，不是新节点类型；
- 不新增必需 JSON 字段，旧工程无迁移；
- 可以先闭环，再按需增加 `tabLabel`、`tabIcon` 等可选元数据。

### 4.3 推荐模型规则

- Tabs 的直接子节点就是页面。
- 新页面固定创建为 `UI_DN_COLUMN`：
  - `wMode = FILL`，`hMode = FILL`；
  - padding 12，gap 8；
  - 名称 `页 N`，ID 由设计器生成且在当前视图内唯一。
- 页面文字默认等于页面节点 `name`；名称为空时显示 `页 N` 作为兜底。
- 页面节点 ID 是跨保存/加载的稳定身份；`selected` 只是页区当前索引的运行时投影。
- 页面数量上限 32。达到上限时设计器禁止新增，并给出状态提示。
- 新工程和设计器新操作只允许容器类型作为页面；旧工程里的叶子页仍可加载、显示和生成，但校验给出警告，且不自动迁移。

## 5. 数据不变量

以下不变量由 `ui_design.c` 集中保证，设计器不重复实现：

| 编号 | 不变量 |
|---|---|
| T1 | Tabs 的 `selected` 只能是 `-1` 或有效页索引 |
| T2 | 无页面时 `selected = -1`；有页面时 `0 <= selected < childCount` |
| T3 | 删除当前页：优先选同索引的下一页，否则选上一页；删空则 `-1` |
| T4 | 删除当前页之前的页：原当前页仍为当前页，索引相应前移 |
| T5 | 页面上移/下移或拖拽重排：当前页跟随页面身份，不跟随旧索引 |
| T6 | 新页插入在当前页之后；如果当前页为 `-1`，插到末尾并选中 |
| T7 | 设计器中页面只能在同一 Tabs 内重排；不允许页面拖出 Tabs，也不允许普通节点拖入 Tabs 成为页面 |
| T8 | 页面数量不超过 32 |
| T9 | 保存/加载后 `selected` 与页面索引一致；越界值读取时归一化 |

### 5.1 建议新增的模型 API

在 `ui_design.h` 增加一组页面语义 API，避免设计器和测试自行维护索引：

```c
int UiDesign_TabsPageCount(const UiDesignDoc *doc, int tabs);
int UiDesign_TabsPageAt(const UiDesignDoc *doc, int tabs, int index);
int UiDesign_TabsSelectedPage(const UiDesignDoc *doc, int tabs);
int UiDesign_TabsSetSelectedPage(UiDesignDoc *doc, int tabs, int index);
int UiDesign_TabsInsertPage(UiDesignDoc *doc, int tabs, int pos,
    const char *id, const char *name);
int UiDesign_TabsRemovePage(UiDesignDoc *doc, int tabs, int index);
int UiDesign_TabsMovePage(UiDesignDoc *doc, int tabs, int from, int to);
void UiDesign_TabsNormalize(UiDesignDoc *doc, int tabs);
```

建议实现方式：

- `TabsInsertPage` 内部调用 `UiDesign_AddNode`，再按 `pos` 重排并更新 `selected`；
- `TabsRemovePage` 先记录当前页 ID，再调用子树删除，最后重新定位/夹取；
- `TabsMovePage` 记录当前页 ID，重排后按 ID 恢复索引；
- `UiDesign_NodeRemove`、`NodeMove`、`NodeMoveUp/Down` 在结构变更后对原/新父节点调用 `TabsNormalize`，保证通用树操作也不会留下坏索引；
- `UiDesign_NodeDuplicate` 复制页面时不自动改变当前页；由设计器选中复制结果后，再通过 reveal 切换。

## 6. 设计器交互

### 6.1 属性页

Tabs 节点选中时，属性页“内容”区改为：

- `当前页`：显示 `页名称 (i/n)`，点击切换到下一页；页面为空时显示“无页”；
- `页签样式`：Line / Pill / Card；
- `页数`：只读 `n / 32`；
- `Enabled`：保留；
- 新增按钮入口（建议放在顶部工具条或属性区）：
  - `新增页`：在当前页之后插入空白 Column 页并选中；
  - `复制页`：复制当前页子树到其后；复用现有 `Ctrl+D` 也可；
  - `删除页`：删除当前页；复用 `Delete` 也可；
  - `上移 / 下移`：复用现有节点操作，但 Tabs 页面下专指页面重排。

页面节点选中时：

- `名称` 即页签文字，改名实时反映到 header；
- 不显示宽/高（当前已隐藏，继续保持）；
- 显示“所属标签页”提示和页索引，便于确认当前编辑的是哪一页。

### 6.2 顶部工具条 / 页面管理入口

第一版建议只增加一个一等动作：**新增页**。原因是现有 `Ctrl+D`、`Delete`、
上移/下移已经能覆盖复制、删除和重排。

新增页入口建议：

- 选中 Tabs 或 Tabs 页面时，顶部工具条出现“新增页”图标/按钮；
- 插入位置：当前页之后；无当前页时追加到末尾；
- 新页自动选中，画布切到新页，树滚动显示。

后续可选增强（不阻塞本轮）：

- 页签尾部设计态 `+` 按钮；
- 右键页签弹出 `新增 / 复制 / 删除 / 重命名 / 上移 / 下移`；
- 属性页页面列表，支持点选和拖拽排序。

### 6.3 页签栏

- 点击页签：切换 `selected`，选中对应页面节点，树自动揭示；
- 当前页在 Line/Pill/Card 下都有明确的视觉状态；
- 空页时绘制“暂无页面 · 新增页”提示，不崩溃；
- 设计态页签不显示关闭按钮，避免和运行时行为混淆；
- header 必须裁剪在 Tabs 内容区内，不能画到画布外。

### 6.4 组件树

- 页面仍是 Tabs 的直接子节点；
- 选中页面内任意后代时，自动揭示其所属页面（现有 `d_tabs_reveal` 保留）；
- 拖拽规则：
  - 同一 Tabs 内页面之间可重排；
  - 页面不能拖出 Tabs；
  - 非容器节点不能拖入 Tabs；
  - 跨 Tabs 的页面移动本轮禁止；
- 删除当前页后，自动选中相邻页；删空则选中 Tabs 本身；
- 复制当前页后，自动选中新页并切到该页；
- 所有结构操作都走 `Tabs*` API 或结构变更后的 `TabsNormalize`。

### 6.5 选中与活动页语义

- “选中节点”是编辑焦点；“活动页”是 Tabs 的 `selected`；
- 点击页签先切活动页，再选中页面节点；
- 树中选中非活动页后代时，自动切活动页，保证画布可见；
- 这种切换属于编辑导航：更新 `selected` 并标脏，但不额外插入一条撤销记录；
- 显式点击页签或属性页“当前页”时，可沿用现有编辑路径，操作结束后进入撤销快照；
- 预览中的页签点击不应修改设计文档的 `selected`（见 7.4）。

## 7. 布局、运行时与绘制

### 7.1 布局

保持现有规则：

- header 高度由 variant 决定：Line 38 / Pill 34 / Card 36；
- 所有页面共享同一页区；
- 页面节点自身的宽高/位置不参与布局；
- 活动页只影响绘制和命中，不影响页面区几何。

### 7.2 静态画布

- 统一使用 `UiTabBar` 的默认样式和指标，不再维护第二套页签宽度公式；
- 建议从 `ui_tab` 暴露一个轻量几何/样式辅助（如 `UiTabBar_HeaderHeight`、`UiTabBar_ItemRect`），
  运行时和设计器共同调用；
- Line：底部 1px 分隔线 + 活动指示条；
- Pill：header 胶囊底 + 活动项实底 + 边框；
- Card：先画非活动页签和内容面板底，再画页面内容，最后覆盖活动页签；
- header 裁剪到 Tabs 内。

### 7.3 运行时

- `dn_draw_node` 的 Tabs 分支保持“header → 页面 → Card 活动页签”的顺序；
- Card 必须调用 `UiTabBar_DrawActive`，否则活动页签不完整；
- Card 页面内容需要有内容面板底色/边框，活动页签与之连通；
- `selected` 在绘制前归一化；
- 页签数量超过 32 时截断并记录/提示（设计器层应提前阻止）；
- 空页显示占位文字，不注册不可用的页面控件。

### 7.4 预览状态

建议：

- 进入预览时记录所有 Tabs 的 `selected`；
- 退出预览时恢复，不把预览中的页签切换写回设计文档；
- 预览中的输入框、开关等状态是否持久化是更广的问题，本轮只保证 Tabs 活动页不被预览污染；
- 如果后续要做完整预览隔离，可以在 `UiDesignInstance` 层复制文档，不应在 Tabs 内单独打补丁。

### 7.5 转场

本轮不接 `UiTabPager`。设计器和生成代码都保持即时切页；转场作为后续独立能力，
避免把输入锁、页面树和代码生成一起复杂化。

## 8. 代码生成与兼容

- 本轮不新增必需 JSON 字段，`format/version` 不变；
- 页面仍是 Tabs 的直接子节点，旧 `.cui` 原样加载；
- 生成代码继续输出 `selected` / `variant`；
- 页面节点继续跳过宽高、x/y 等无效尺寸字段；
- 生成文件仍由 `UiDesignInstance` 解释模型，因此运行时修复会自动覆盖生成代码；
- 0 页 Tabs 允许存在，但校验给出警告；
- 32 页以上在设计器校验阶段阻止新增/生成；
- 若后续增加 `tabLabel`/`tabIcon`/`tabEnabled`，作为可选字段追加，旧文档缺省即默认行为。

## 9. 校验与错误处理

建议在 `UiDesign_Validate` 增加：

| 检查 | 级别 | 处理 |
|---|---|---|
| Tabs 页数 > 32 | Error | 阻止生成并提示 |
| `selected` 越界 | 自动修复 | 归一化到有效索引或 `-1` |
| Tabs 无页面 | Warning | 允许保存/生成，但提示空页 |
| 页面不是容器类型 | Warning | 旧文档兼容；设计器禁止向其内部插入 |
| 页面名称为空 | Warning | header 显示兜底名 |
| 页签总宽超出 Tabs 宽度 | Warning | 提示运行时会截断，建议减少页签/换 Pill/加宽 Tabs |
| 页面被拖出/外部节点拖入 | 操作阻止 | 状态栏说明原因 |

## 10. 测试与验收

### 10.1 模型测试

- 新增页：空 Tabs 插入后 `selected` 正确；
- 在当前页后插入：索引和选中页正确；
- 删除当前页：同索引下一页优先，否则上一页；
- 删除当前页之前的页：当前页身份不变，索引前移；
- 删除全部页：`selected = -1`；
- 页面上移/下移：当前页跟随；
- 重排非当前页：当前页索引正确偏移；
- 超过 32 页：拒绝新增/校验失败；
- 页面拖出、非容器拖入：操作被拒绝；
- JSON 往返：多页、`selected`、空页、越界归一化；
- 布局：所有页面共享页区，页面尺寸被覆盖；
- 命中：只命中活动页。

### 10.2 代码生成测试

- 空页 Tabs 可生成；

## 13. 实施记录（2026-11-24）

M1–M4 已按方案落地，实际取舍如下：

| 项 | 落地结果 |
|---|---|
| 页面模型 | 直接子节点即页面；新增 `UiDesign_TabsPageCount/PageAt/SelectedPage/SetSelectedPage/InsertPage/RemovePage/MovePage/Normalize` |
| 不变量 | 空 Tabs 的 `selected=-1`；非空始终落在有效页；增删/移动/JSON 读入后自动归一化 |
| 页数上限 | `UI_DN_TABS_MAX_PAGES=32`；属性页新增与模型 API 双重拦截 |
| 新增入口 | 放在属性页“页面操作 → ＋ 新增页”，Tabs 自身和页内节点都可触发；新页固定为 Column，插入当前页之后并立即选中 |
| 结构约束 | 页面只能在所属 Tabs 内重排；页面不能拖出，普通节点不能直接拖入 Tabs |
| 删除语义 | 删当前页后选中下一张，否则保持原活动页身份；删空后 `selected=-1` |
| 绘制一致性 | 新增 `UiTabBar_Measure`，运行时 `DrawEx` 与设计器静态画布共用同一套 header/item 几何 |
| Card | 运行时补页面底色 + `UiTabBar_DrawActive` 二阶段；静态画布同样在页面内容后补画活动页签 |
| 预览隔离 | 进入预览保存所有 Tabs 的 `selected`，退出预览恢复，预览点击不写回设计文档 |
| 撤销 | 显式新增/删除/重排记撤销；仅切换活动页只标脏，不单独入栈 |
| 校验 | 空 Tabs、非容器页、超过 32 页均有校验/状态提示；生成与生成预览会附带警告 |
| 测试 | 新增 Tabs 页面模型测试与生成代码断言；`cui_designer_test` 316/316 通过；21 个 headless 测试套件全绿 |

已知边界：静态画布与运行时共享几何规则，但本轮未做逐像素人工视觉比对；Line 指示条动画、Pill/Card 主题色细节仍以运行时为准。
